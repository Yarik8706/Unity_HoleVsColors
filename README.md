# Unity_HoleVsColors

## 📋 Описание проекта
**Hole vs Colors** — это гиперказуальная мобильная игра, в которой игрок управляет черной дырой, собирающей объекты определенного цвета. Игра разработана для платформы Яндекс.Игры с поддержкой монетизации через рекламу и внутриигровой магазин.

### 🎮 Реализованные системы:
- **Система управления дырой** — динамическое управление через джойстик с деформацией меша в реальном времени
- **Система уровней** — прогрессивная система с предустановленными и случайными уровнями
- **Система сохранений** — интеграция с Яндекс.Игры для сохранения прогресса игрока
- **Система монетизации** — внутриигровая валюта, магазин предметов и реклама
- **Система тем** — динамическая смена цветовых схем уровней
- **UI система** — адаптивный интерфейс с мультиязычной поддержкой
- **Система аналитики** — интеграция с Яндекс.Метрикой для отслеживания игровых событий
- **Система прогресса** — визуализация прогресса уровня и рейтинговая система

### 🛠 Технологический стек:

#### Движок и версия:
- **Unity 2022.3.18f1 LTS** — игровой движок

#### Языки программирования:
- **C#** — основной язык разработки

#### Unity пакеты и модули:
- **TextMesh Pro 3.0.8** — продвинутая система рендеринга текста
- **Unity Ads 4.4.2** — система монетизации через рекламу
- **Unity Analytics 5.1.0** — аналитика игровых метрик
- **Unity Authentication 3.3.0** — система аутентификации
- **Visual Scripting 1.9.1** — визуальное программирование
- **2D Sprite 1.0.0** — работа с 2D графикой

#### Сторонние библиотеки и SDK:
- **DOTween (Demigiant)** — мощная библиотека для анимаций и твининга
- **Yandex Games SDK** — интеграция с платформой Яндекс.Игры
  - Сохранение прогресса
  - Показ рекламы (fullscreen, rewarded)
  - Мультиязычность
  - Яндекс.Метрика
- **Joystick Pack** — готовое решение для мобильного управления

#### Основные технологии и паттерны:
- **Mesh Deformation** — динамическая деформация меша для создания эффекта черной дыры
- **Singleton Pattern** — для управления глобальными системами (LevelControl, UIManager)
- **Object Pooling** — оптимизация производительности
- **ScriptableObjects** — для хранения данных уровней и тем
- **Particle Systems** — визуальные эффекты победы
- **DOTween Animations** — плавные анимации UI и игровых объектов

#### Платформы:
- **WebGL** — основная платформа для Яндекс.Игры
- **Mobile (Touch Controls)** — поддержка мобильных устройств
